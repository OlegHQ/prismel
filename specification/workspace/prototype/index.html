THE CENTRAL PROPOSAL

Different views.
The same meaning.

Artists can follow shapes and connections. Coders can name, abstract and refactor. A parameter can grow from a number into an expression, then into a reusable function without changing what it means.

Research, language design & open decisions ↗
01

Grouping organizes. Functions reuse.

A group is a visual frame. A function has a typed interface, a shared definition and independent arguments at every call.

02

The editor is a composition, too.

Panels are typed values. Preview a layout without losing the host controls that let you recover it.

03

Incomplete work has a place.

A source draft can be broken. The applied document cannot. Check, inspect the error, fix and apply in one undoable step.

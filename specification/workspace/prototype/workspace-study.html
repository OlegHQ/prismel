Four ways in

Each one opens the studio at the right place.

The central proposal

Different views.
The same meaning.

Artists follow shapes and connections. Coders name, abstract and refactor. A parameter grows from a number into an expression, then into a reusable function, without changing what it means.

Grouping organizes. Functions reuse.

A group is a visual frame. A function has a typed interface, one shared definition and independent arguments at every call.

The editor is a composition too.

Panels are typed values. Preview a layout without losing the host controls that recover it.

Incomplete work has a place.

A source draft can be broken. The applied document cannot. Check, read the error, fix and apply as one undoable step.

What is real

One AST feeds graph, list, text, inspector, preview and layout. Shared and independent functions, typed connection menus, atomic apply, 60-step undo, cycle, arity, type and context checks, and restricted value macros.

What is not

Not a compiler or a renderer. The flower is a JavaScript illustration, not Prismel geometry. No node creation, wire dragging, panning or position editing. Full hygienic macros and lossless source identity are proposed for the native milestone.

Session only

Visual groups are metadata and never reach exported Lisp. Reloading loses edits, so copy the Lisp first. Parameter-drive restoration is specified natively and not simulated here.

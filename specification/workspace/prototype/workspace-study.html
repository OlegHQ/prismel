Five ways in

Each one opens the studio at the right place.

The central proposal

Different views.
The same meaning.

Artists follow shapes and connections. Coders name, abstract and refactor. A parameter grows from a number into an expression, then into a reusable function, without changing what it means.

The sidebar is a map, not a menu.

It lists contexts and functions, shows what each graph reads and what reads it, lists the shell's own panels, and takes drags: pull a function or graph onto the canvas to place it.

Selection scopes the code.

Select a node and the Lisp panel shows that node plus what it depends on, as a runnable snippet. Double-click a line to edit it in place.

The editor is a composition too.

Panels are typed values. Dragging a divider writes a ratio into the editor graph. Restore layout stays outside it, so a broken shell can always be recovered.

What is real

One AST feeds every panel. Dragging wires, scrubbing values, folding and unfolding, adding and deleting nodes, panel split, close, retype and resize all rewrite the Lisp and pass the checker, or are rejected with a reason. Undo covers each gesture.

What is not

Not a compiler or a renderer. The flower is a JavaScript illustration. No wire bending, marquee select or node search by type beyond the add palette. Full hygienic macros and lossless source identity are proposed for the native milestone.

Session only

Node positions and visual groups are metadata and never reach exported Lisp. Reloading loses edits, so copy the Lisp first. Parameter-drive restoration is specified natively and not simulated here.

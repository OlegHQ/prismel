# PXUI baseline before the immediate-mode `Ui` rewrite (2026-09-24)

Machine: Apple M1, 8 cores, 16 GiB, macOS 26.2 (Darwin 25.2.0), OCaml 5.3.0,
Dune `release` profile, one domain. Development
working tree.

The previous `bench_pxui` assumed 28 pt rows while PXUI uses 24 pt rows, so
its "drag" pressed below the target slider and measured a miss. The fixed
benchmark aborts when the drag emits no change.

```sh
dune build --profile release tools/bench_pxui.exe tools/bench_pxui_graph.exe
PRISMEL_PXUI_BENCH_WIDGETS=1000 ./_build/default/tools/bench_pxui.exe
./_build/default/tools/bench_pxui_graph.exe
```

| case | seconds | allocated bytes | count |

| retained reconcile, unchanged | 0.000001 | 376 | – |

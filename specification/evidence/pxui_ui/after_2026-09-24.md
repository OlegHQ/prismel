# PXUI after the immediate-mode `Ui` rewrite (2026-09-24)

Same machine, profile, and commands as
[`baseline_2026-09-24.md`](./baseline_2026-09-24.md): Apple M1, 8 cores,
16 GiB, macOS 26.2, OCaml 5.3.0, Dune `release`, one domain.

```sh
dune build --profile release tools/bench_pxui.exe tools/bench_pxui_graph.exe
./_build/default/tools/bench_pxui.exe
./_build/default/tools/bench_pxui_graph.exe
```

The retained widget list, `Pxui.Runtime`, and `pxui_next` no longer exist,
so rows compare the operations a sketch performs rather than identical
functions. Every `Ui` row is a complete UI frame: event routing, build,
layout, paint into the instance list, and scene publication. The panel is
bounded to 760 points, so only visible rows paint.

## Panel (1000 sliders, median of 7)

| operation | before | after |
| --- | ---: | ---: |
| describe a changed panel (`scene`, uncached → full frame) | 1.910 ms, 5.75 MB | 1.003 ms, 2.78 MB |
| same after a model-side value change | — (1.932 ms, 12.1 MB inspector sync) | 0.860 ms, 2.78 MB; no sync exists |
| press/drag/release | 0.412 ms, 0.77 MB, no scene | 0.752 ms, 2.79 MB, including paint |
| one drag frame (event + picture) | 1.712 ms, 5.71 MB | 0.754 ms, 2.78 MB |
| draw batches, 7-widget kit panel | 53 | 2 |

## Graph canvas, zoomed fully out and panning (median of 10 frames)

| nodes | before (s/frame, B/10 frames, batches) | after |
| ---: | --- | --- |
| 100 | 0.015452, 562,079,616, 116 | 0.000290, 9,583,536, 1 |
| 1,000 | 0.015770, 640,279,088, 762 | 0.001549, 38,733,496, 1 |
| 10,000 | 0.015604, 640,279,088, 762 | 0.001426, 38,733,496, 1 |

The dot grid is one quad and wires are instanced Bézier segments, so the pan
frame no longer allocates a primitive per dot. Node and wire hit-test p99
stays 1–3 µs at 10,000 nodes. Wire hits now measure distance to the
flattened Bézier; the 10,000-query hit loop allocates 51.7 MB (was 16.8 MB)
for those flattening tuples.

## Workspace

`test/test_sketch_ui` asserts the full 3D workspace — pane chrome, graph
canvas with tiles and labels, camera inspector, and status bar — paints in at
most 16 UI batches; it currently paints in 5. Before, every label was a
separate textured draw between geometry runs.

## Typography

`lib/pxui/test_ui_parity` renders every kit widget natively at 2× and
compares it with the retained PXUI's capture
(`lib/pxui/fixtures/kit_panel_2x.png`): 272 pixels differ, all inside 1-point
stroke corner squares and the XY knob; all text pixels are identical.

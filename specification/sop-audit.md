# SOP production-parity audit

Status: active parity program. Last audited 2026-08-05.

## Meaning of parity

Prismel does not claim global Houdini SOP parity. Each public node is graded
against the applicable behavior in SideFX's current documentation:

- **Full**: all behavior relevant to Prismel's polygon/curve geometry model is
  implemented, including attributes, groups, errors, cancellation, and exact
  domain-count determinism.
- **Production subset**: the documented contract is complete and reliable, but
  intentionally covers fewer modes than Houdini. The missing modes are listed.
- **Partial**: useful behavior exists but a required production mode or
  preservation rule remains absent.
- **Missing**: no public placeholder is exposed.

Every promotion to Full or Production subset requires cardinality/complexity
documentation, malformed-input tests, exact one/four-domain comparison when
parallel, cancellation coverage for long work, and a visual pixel regression
when output is renderable.

OpenSubdiv 3 removed hierarchical edits from its supported subdivision
specification. They are therefore not recorded as a current Subdivide parity
gap; Prismel does not reintroduce a deprecated extended-specification feature
that Houdini's current OpenSubdiv path does not document.
Likewise, Houdini's current Subdivide SOP exposes finite Depth refinement, not
limit-surface output. OpenSubdiv limit evaluation is a separate VOP/API
operation and is not misclassified here as a missing Subdivide parameter.

## Shared algorithm ownership

PDK is the single packed modeling core. `Topology_index` derives point-corner
CSR incidence and an integer-key undirected half-edge index in expected linear
time, including stable opposites, boundaries, and non-manifold counts. Geom
may prepare ergonomic polygon/curve inputs and adapt results, while Procedural
may compose Geom and PDK operations. Neither layer owns a second packed mesh
algorithm.

Existing Geom algorithms are migration inputs, not an alternate production
backend. Each operation moves to PDK with attribute/group semantics,
cancellation, exact domain-count regressions, malformed-topology coverage, and
a measured scale fixture before the old kernel is retired.
